# Steam Cloud

Steam Cloud can conflict with local save-profile swapping. If Steam Cloud restores or uploads files after the launcher changes the active save folder, the selected profile may not be the save state that the game actually uses.

For the first release, disable Steam Cloud manually for this game if Steam offers the option:

1. Open Steam.
2. Right-click `Librarian: Tidy Up the Arcane Library!`.
3. Choose `Properties`.
4. Open `General`.
5. Turn off Steam Cloud for this game.

The launcher does not automatically change Steam configuration. Steam settings can be stored in multiple files and may be rewritten by the Steam client, especially while Steam is running.
